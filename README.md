🏠 Real Estate Sales Analytics powerBi project04
This Power BI project analyzes real estate market trends using interactive dashboards. It provides insights into house sales, regional performance, pricing trends, offer vs purchase prices, SQM rates, inflation, and sales growth. The project helps understand housing market behavior and supports data-driven decision-making.
📌 Project Overview
    The House Market Insights Dashboard is a Power BI project focused on analyzing real estate market trends and sales performance. The dashboard provides             interactive visualizations to understand property pricing, regional sales distribution, SQM rates, inflation, interest rates, and purchase behavior.

📊 Features
    1.Regional house sales analysis
    2.Offer Price vs Purchase Price comparison
    3.Sales growth by sales type
    4.SQM (Square Meter) price analysis
    5.House type performance insights
    6.Inflation, interest, and yield comparison
    7.Interactive filters for region, city, and sales type
🛠 Tools & Technologies
  1.Power BI
  2.Excel Dataset
  3.Data Visualization
  4.Data Analysis
📈 Dashboard Insights
  The project helps identify:
    1.High-performing regions in the housing market
    2.Trends in property pricing
    3.Sales patterns across different house types
    4.Market growth and investment opportunities
